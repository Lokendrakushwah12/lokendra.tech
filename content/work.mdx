<RoleHeading title="Software Engineer at Keychain" date="Sep 2025 - Present" />

Keychain is an ERP for food & beverage manufacturers. I ship features across the frontend and the ERP data layer, run frontend releases, and I'm on call - so performance work and production incidents are as much the job as the roadmap is.

**Splitting the monolith.** I migrated operator-mode, workflow and production routes out of the monolithic dashboard app into a standalone Next.js app - 34 commits, new route groups, dashboard kept as a rollback target. CI build times went from 16-18 minutes down to 7-9.

<MonolithSplit />

**Owning releases.** I run frontend releases end to end: sequencing dependent FE/BE merges across three services, resolving release-branch conflicts, verifying on production and writing the release notes. The largest shipped 10 features and fixes in a single release with zero rollbacks.

**AI extraction.** I built Customer AI extraction - the shared platform data layer plus the review, approval and bulk error-resolution UI - and fixed false DUPLICATE flagging in document ingestion, load-tested against a 4,500-row customer file.

<ExtractionPipeline />

**Root-cause work.** Traced 119 of 326 sales orders with null address foreign keys back to a single ERP migration batch. Bounded 11 vendor billing-address overwrites to one integration window using Postgres audit tables. Fixed multi-page dispatch PDFs rendering overlapping text, work-order quantities silently zeroed by 2-decimal rounding, and delivery dates shifting a day because date-only values were stored as epoch timestamps.

<IncidentTrace />

**The demo platform.** I own the sales demo environments: provisioning went from a full engineering day to under 30 minutes, I re-synced environments that had drifted ~2 months behind production, and caught a 40s+ Start Production regression by benchmarking accounts before it reached a live customer call.

**Design work.** A full UI overhaul of the internal AI platform - 261 files, +9.2K/-2.5K LOC - putting a design token behind every colour utility, a shared Base UI component library, dagre-routed workflow graphs (18 edges, 0 crossings) and WCAG 4.5:1 text contrast.
