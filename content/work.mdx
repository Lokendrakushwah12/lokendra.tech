<RoleHeading title="Software Engineer at Keychain" date="Sep 2025 - Present" />

Keychain is an ERP for food & beverage manufacturers. I work on the internal AI agent platform and ship features across the frontend and the ERP data layer. I also run frontend releases and I'm on call, so performance work and production incidents are as much the job as the roadmap is.

**The internal AI platform.** Keychain's internal AI agent answers questions about our customers using sales calls, the CRM, email and our data warehouse. It also runs workflows that act on what they find, like a daily brief for each sales rep. Most of the work is deciding what the agent is allowed to see and do, and for whom.

- Built access control: each person only sees the data they're allowed to, can ask for more from their profile, and admins approve it in one place.
- Let people build their own workflows from SQL queries, AI steps and small bits of code. A workflow only sees what its owner can see, and its queries are checked before it can be turned on.
- Built a chat where you describe a workflow in plain English and the agent builds or changes it for you.
- Built a web search step that text on a web page can't take over, with a daily spending limit on every search and AI call.
- Workflows can now make files (spreadsheets, PDFs, Word docs, slides), share report pages, send Slack messages with buttons and send email from the owner's own inbox. Docs they make can be edited, with full version history.
- Built a daily meeting digest for sales reps, with a pre-call brief from the CRM and buttons to mark each meeting as held, no-show or rescheduled.
- Fixed the safety checks that decide who a workflow may message, and added a scored test set for the AI that reviews every change.
- Redesigned the whole UI on a shared component library, with live progress while a workflow runs and Cmd+K search.

211 PRs (167 merged, 44 open), +138.7K/-16.3K lines of code.
